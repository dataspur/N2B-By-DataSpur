## How BullshID Works (60-Second Overview)

### Step 1: Scan ID Front & Back (1 second)
Bouncer opens BullshID app on iPad, scans driver's license front and back using camera.

**What Happens**:
- Barcode (PDF417) decoded and validated
- OCR extracts text (name, DOB, license #, expiration)
- Document type identified (TX DL, CA DL, passport, etc.)

### Step 2: Capture Selfie (1 second)
Patron looks at camera for quick selfie.

**What Happens**:
- Face detected and extracted from selfie
- Compared to ID photo using AI (99% accuracy)
- Age estimation validates 21+ requirement

### Step 3: Instant Result (1 second)
App displays result in 3 seconds total:

**🟢 PASS (Green Screen)**
- ID is legitimate, person matches photo, age 21+
- Bouncer allows entry

**🔴 FAIL - FAKE ID (Red Screen)**
- Barcode mismatch, hologram missing, or known fake template
- Bouncer denies entry, confiscates ID (if appropriate)

**🟡 ALERT - REVIEW REQUIRED (Yellow Screen)**
- Expired ID, photo mismatch, or underage (under 21)
- Bouncer uses discretion (can override if justified, e.g., person turned 21 yesterday but ID not updated)

### Hyperspectral Layer (Pro Tier Only)
For suspicious IDs, bouncer activates UV/IR mode:
- iPad filters analyze hologram under UV light (365nm)
- IR scan detects ink composition (authentic vs. printed)
- Algorithm compares to database of real Texas/state holograms
- Adds 2 seconds to scan time but increases detection accuracy to 99%
